Build part 2 of the deepWidgets remote-access prototype in this repo: `worker/` (Cloudflare Worker + Durable Object relay + OAuth remote MCP), bridge deltas, and the end-to-end suites. `stub/` and `bridge/` already exist with unit tests (part 1) — read them first and reuse; keep their frame protocol (hello/call/result JSON frames + literal ping/pong) and assertion claims.

Spec: `ARCHITECTURE.md` section 14 (the round-2 spec, copied in this repo) plus the corrections in `CRITIQUE-r2.md` (Sonnet). Where they conflict, follow these decisions:
- N1: `completeAuthorization` cannot take a grantId. Put `{ owner, deviceId, widgets, scope }` in props; get the grant id via the provider's `tokenExchangeCallback` (it receives grantId; return `accessTokenProps` including `grantId`) — verify in node_modules/@cloudflare/workers-oauth-provider/dist/oauth-provider.d.ts. The tool handler reads props via `getMcpAuthContext()` from `agents/mcp/server`; validate the props shape at runtime and register zero tools if invalid.
- N2: DO waits a fixed 30 s for a result -> `device-timeout`; the bridge enforces its own local timeout (10 s default).
- MVP cut: ONE device. Device id and the SHA-256 hash of the device credential come from Worker vars/secrets (`DEVICE_ID`, `DEVICE_CREDENTIAL_SHA256`); no mint endpoint, no DEVICE_ID_KEY MAC. `/device/connect` compares the hash in constant time before addressing the DO.
- Bridge replacement: a new authenticated socket is refused (409) if the existing one auto-ponged within the last 45 s (`getWebSocketAutoResponseTimestamp`); otherwise it replaces it and audits `bridge-replaced`.
- Lockout (N6): per-IP counter (CF-Connecting-IP, fallback 'unknown') plus a global ceiling, in a small Lockout DO, for /authorize POST and /admin/*: 5 failures / 15 min per IP -> 429; global 50 / 15 min -> 429. Document break-glass in README (delete the Worker / rotate OWNER_PASSCODE).
- Drop: DO rate buckets, in-flight caps, `slow` action/requestId retry test, two-grant test. Keep `/__stub/fault` if part 1 has it; if not, skip the 502/503 tests.
- `allowedHostnames`/origin options of createMcpHandler: set from PUBLIC_URL so the deployed host works.
