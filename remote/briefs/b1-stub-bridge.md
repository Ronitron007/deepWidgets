bridge/ (bridge/src/*.ts; entry bridge/src/main.ts runnable via `npx tsx bridge/src/main.ts`):
- assertion.ts: verify compact JWS EdDSA (Ed25519) with node:crypto against a pinned public JWK; claims per section 5; checks: signature, iss 'dw-relay', aud = this device id, exp (with server clock offset, 5 s tolerance), exp-iat <= 60, iat >= bridge start (minus tolerance), unseen jti (replay.ts cache until exp), tool in allowlist, scope covers tool (widgets:read for widget_list/widget_describe/widget_changes; widgets:call for widget_call), ah = base64url SHA-256 of the exact argsJson bytes, slug (args.slug when present) in wid (or wid '*') and never 'main'. Return {ok, claims} or {ok:false, reason}.
- allowlist.ts: literal frozen list of exactly widget_list, widget_describe, widget_call, widget_changes.
- local.ts: read mcp.json, handshake with POST /mcp/token (agent 'remote:<short client id>' sanitized to valid chars, 16 random bytes base64url challenge, verify proof with timingSafeEqual — refuse the server if proof is wrong), cache per client per `started`; forward with the MCP SDK Client + StreamableHTTPClientTransport and the bearer; on 401 re-read mcp.json and re-handshake once; strip `source` fields from widget_describe results; cap result at 256 KiB.
- relay protocol (main.ts): connect with `ws` to `${DW_WORKER_URL}/device/connect` (http->ws, https->wss) with header `Authorization: Bearer <device credential read from DW_DEVICE_CREDENTIAL_FILE>`; frames are JSON: server->bridge `{type:'hello', serverTime, deviceId}`, `{type:'call', id, assertion, argsJson}`; bridge->server `{type:'result', id, ok:true, result}` or `{type:'result', id, ok:false, error:{code, message}}` with codes 'assertion-rejected', 'killed-locally', 'local-unavailable', 'local-error'. Tool name comes only from the verified assertion. Kill file: if `DW_KILL_FILE` exists (default `~/.deepwidgets-bridge/KILL`, never inside $DSH_HOME/deepwidgets and never settings.json), refuse every call with killed-locally. Reconnect with jittered backoff 1-30 s. Export a `startBridge(opts)` returning { close } for tests. Never log the device credential, bearer tokens or nonce.
