# Plan for the agent library `agent_library.plan`

This plan implements `docs/specs/agent-library.md`. The process is `widget_mvp.plan.process`.

## Units `agent_library.plan.units`

| Unit | Change | Check | Mutant that must fail the check | Needs |
|---|---|---|---|---|
| `library.main_split` | `agent_library.main_split` | The typecheck and the lint pass. The shell page builds. `DSH_SMOKE_WIDGET=sample` passes, with its live refresh. `DSH_SMOKE_WINDOWS=1` passes. The shell source imports the core only through `@deepwidgets/widget-kit`, and the core imports no component library. | The core does not put the refresh bridge in `children`: the live refresh of `DSH_SMOKE_WIDGET=sample` fails. | none |
| `library.build_gate` | `agent_library.build_gate` | The typecheck and the lint pass. `widgets-create` installs a bundle with a good page, and the built page is in the profile folder. The install refuses a page with a type error, a page that imports a package that is not on the list, a page with a changed fixed file or `dw-core` block, and a page whose component throws in the render check. In a CLI host, a good page installs with the warning that the render check was skipped. A bundle with no `page/` installs as before. | Remove the render check: the page whose component throws installs, and the check fails. | `library.main_split` |
| `library.serving` | `agent_library.serving` | The typecheck and the lint pass. With the app, the window of a bundle with a page shows the component of that page, at the widget origin of its slug. `DSH_SMOKE_WIDGET=sample` passes: `sample` shows the shared shell at its widget origin, with its live refresh. From the page of one slug, a request for its own program gets 200, and a request for the program of another slug gets 403. After an install with new page sources, the open window shows the new page. After an install with no `page/`, it shows the shared shell. A renderer that ends two times in 60 s leaves the window on the shared shell with the notice. A slug that starts with `xn--`, a slug that ends with `-`, and a slug of 63 characters each get a window that loads. | Remove the slug scope from the API route: the request for the other slug gets 200, and the check fails. | `library.build_gate` |
| `library.fence_warn` | `agent_library.fence_warn` | The typecheck and the lint pass. `widgets-create` installs a page that imports a file outside the page folder, a page whose stylesheet imports a file outside it, a page with a bare `image-set()` string of such a file, and a page with `new URL` of such a file. Each install applies, and its answer has a warning that names the file. The host log has a line for each. A page with a type error, a changed fixed file, an `@plugin`, or a PostCSS config file is refused as before. `allowedFolders` does not hold a workspace package that only another workspace package names as a development dependency. | The output fence adds no warning: the install has no warning, and the check fails. | `library.build_gate` |
| `library.guide` | `agent_library.guide` | The typecheck and the lint pass. `widgets-mcp` and `widgets-create` pass. `deepwidgets_modes` lists `interact`, `create`, and `library`. `library_template` gives five files. A bundle from `widget_template` and `library_template` passes each gate when `src/index.ts` sets `catalog` to the id of the example child, with no other change. With no `catalog`, the install fails with `wrong-catalog`. With the app, and with one use of the example component in the program, its window shows the example component. The check writes `{ "modes": { "library": false } }` to the settings file. Then `library_template` returns `mode-off`, `widget_install` of a bundle with `page/` returns `mode-off` with the mode `library`, and a bundle with no `page/` installs. `widget_guide` with the mode `library` gives the page guide, in at most 8,000 characters. | Remove the gate of the mode `library` from `widget_install`: the bundle with `page/` installs while the mode is off, and the check fails. | `library.serving`, `library.fence_warn`, `main.runtime` |
