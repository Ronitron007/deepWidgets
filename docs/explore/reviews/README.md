# deepWidgets design reviews

These reviews capture the November 2026 product, pliability, UI architecture, and security evaluations. The [product direction](../../specs/product-direction.md) supplies the authoritative brief for ongoing work.

- [Ephemeral agent surface design](ephemeral-surface-design.md) explains the local-first proposal, the lifecycle and decision loop, and ways to extend authoring once those work.
- [Shared widget interactions and Vercel UI SDK](widget-interaction-ui-sdk.md) identifies the common widget behavior and the evidence needed to adopt the SDK.
- [System architecture and remote access](architecture.md) maps the runtime and the device authority that compatible hosted connectors will need.
- [Decision history and agent handoffs](decision-history.md) traces the prototype decisions, window-bar and packaging blockers, and how development and review agents receive instructions.
- [Design workarounds](design-workarounds.md) follows failure sequences across components and proposes ownership, activation, and recovery changes.
- [Initial ephemeral-surface review](future-of-ui-verdict.md) records the broader proposal that prompted the local milestone and SDK comparison.
